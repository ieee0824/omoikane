# SVG DOM 最小実装と getSVGDocument

## 目的

SVG 文書の DOM インターフェース最小セットと `getSVGDocument()` を実装し、
Acid3 bucket5 の SVG 系テストを解放する。

## 前提

- 016-14-1(XML サブ文書パース)が先行。SVG 文書が DOM 化されることが前提

## 対象テスト(Acid3)

- test 69 の完遂(svg.xml の `<text>` 要素操作)
- test 74: `iframe.getSVGDocument()` / SVG contentDocument
- test 75: SVGRectElement 等のインターフェース公開(instanceof / コンストラクタ名)
- test 77: `SVGTextContentElement.getNumberOfChars()`
- test 79: SVG 関連の残検査(実測で特定)

## スコープ

- SVG 要素の DOM クラス(SVGSVGElement / SVGRectElement / SVGTextContentElement 等、
  Acid3 が触るものに限定)を wrapNode のディスパッチに追加
- `getNumberOfChars()` 等、Acid3 が呼ぶ最小メソッド
- `iframe.getSVGDocument()` / `object.getSVGDocument()`
- レンダリングは対象外(DOM API のみ。既存の SVG 描画(src/svg)との整合は確認)

## 受け入れ条件

- 対象テストのうち SVG DOM 起因のものが前進する(実測で個別記録)
- 既存テスト・Acid3 スコアの維持以上

## 実装結果

- SVG 名前空間の `svg` / `rect` / `text` をそれぞれ
  `SVGSVGElement` / `SVGRectElement` / `SVGTextElement` としてラップ
- `SVGTextContentElement.getNumberOfChars()` と Acid3 が確認する
  `SVGRectElement.width` を最小実装
- `<iframe>` / `<object>` に `contentDocument` と `getSVGDocument()` を実装し、
  SVG 文書以外では `null` を返す
- Acid3 Faithful / Direct とも 93/100 から 97/100、index 100。
  test 69 / 74 / 75 / 77 / 79 はすべて PASS
- `cargo build -j1`、`cargo test --lib -j1`、`cargo test --tests -j1` 成功
