# Acid2テスト合格

Acid2 (https://acid2.acidtests.org/) はCSS 2.1準拠を検証するテストページ。
リファレンス画像と同一のレンダリング結果を出力できることを目標とする。

## Acid2が要求する主要機能

- CSS ボックスモデル（margin, padding, border の正確な計算）
- CSS テーブルレイアウト（display: table / table-row / table-cell）
- 絶対配置・固定配置（position: absolute / fixed）
- overflow: hidden によるクリッピング
- 生成コンテンツ（::before, ::after + content プロパティ）
- data: URI のサポート
- PNG 画像の描画（alpha 透過含む）
- CSS パーサーのエラーリカバリ（不正なプロパティの無視）
- 正しいカスケード・詳細度計算（実装済み）
- 背景色・背景画像（background-color, background-image）
- z-index による重なり順の制御
- visibility: hidden
- line-height, vertical-align
