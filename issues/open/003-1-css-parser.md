# CSSパーサー

CSS Syntax Module (Level 3) に基づくパーサーの実装。

## タスク
- [ ] CSSトークナイザ（ident, number, string, delim等）
- [ ] スタイルシートのパース（ルールリスト）
- [ ] セレクタのパース（型、クラス、ID、属性、擬似クラス、擬似要素）
- [ ] 結合子のパース（子孫、子、隣接、一般兄弟）
- [ ] プロパティ値のパース（キーワード、長さ、色、関数等）
- [ ] @ルール（@media, @import, @font-face）
- [ ] ショートハンドプロパティの展開（margin, padding, border等）
