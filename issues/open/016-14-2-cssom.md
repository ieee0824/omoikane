# CSSOM(styleSheets / cssRules / insertRule / ownerNode)

## 目的

CSSOM の最小実装で Acid3 test 72 を解放する。

## 対象テスト(Acid3)

- test 72: `document.styleSheets` → `cssRules` の検査、`insertRule` による動的追加、
  `ownerNode`、`<style>` 要素の動的な再スタイル反映

## スコープ

- `document.styleSheets`(文書内 `<style>`(と将来の link)の CSSStyleSheet リスト)
- `CSSStyleSheet`: `cssRules`(CSSRuleList)/ `insertRule(rule, index)` / `deleteRule(index)` /
  `ownerNode`
- `CSSStyleRule`: `selectorText` / `style`(宣言への読み取りアクセス)/ `cssText`
- insertRule 等の変更が resolver(文書単位キャッシュ)の dirty 化に接続され、
  getComputedStyle に反映される
- acid3.html の test 72 の期待に合わせる(cssRules の数・順序・selectorText 等)

## 受け入れ条件

- Acid3 test 72 が PASS する
- 既存テスト・Acid3 スコア(90/100)の維持以上

## 実装結果

- `document.styleSheets` を文書内の `<style>` の tree order で live 列挙
- live `cssRules`、`CSSStyleRule` の `selectorText` / `cssText` / 読み取り用 `style`、`ownerNode` / `href` を実装
- `insertRule` / `deleteRule` を既存 CSS パーサの構文検証と接続し、`SyntaxError` / `IndexSizeError` を実装
- CSSOM 編集を `<style>.textContent` mutation に集約し、文書単位 StyleResolver の既存 dirty 経路へ接続
- Acid3 test 72 PASS、Faithful / DirectDrive とも 91/100
