# テーブルレイアウト

CSS テーブルレイアウト（display: table / table-row / table-cell）を実装する。
Acid2ではテーブルベースの配置が多用されている。

## タスク
- [x] display: table / table-row-group / table-row / table-cell の認識
- [x] テーブル幅の計算（固定テーブルレイアウト）
- [x] 列幅の分配アルゴリズム
- [x] セルの高さ計算と行内の垂直揃え
- [x] テーブルのボーダーモデル（border-collapse / border-spacing）
- [x] 匿名テーブルボックスの生成（仕様に基づく補完）
