# Omoikane v0.4.0

v0.3.1以来のブラウザ機能・描画・互換性の改善をまとめたリリースです。`Cargo.toml` のバージョンは0.4.0です。

## セキュリティ

- ページのJavaScriptから内部ホストバインディングを経由して別オリジンのDOM、Cookie、ストレージへアクセスできる問題を修正しました。ホストバインディングの公開範囲を限定し、Rust側でも呼び出し元と対象文書のオリジンを検査します。修正は `3de073a` に含まれます。
- この修正はv0.3.2以前には含まれません。該当バージョンを利用している場合はv0.4.0へ更新してください。

## 主な変更

- DOMとブラウザAPIを拡充しました。iframeと`postMessage`、Shadow DOM、ページ可視性、Fullscreen API、検索などの挙動を改善しています。
- CSSのカスケードレイヤー、登録済みカスタムプロパティ、数式、複数カラム、フォント読み込み、印刷時の`@page`などを追加・改善しました。
- Cookieの共有とサイト制限、HTTP処理、CDPの安定性を改善しました。
- WPTとブラウザ挙動の回帰テストを拡充しました。JIT関連の検証は継続していますが、実験用featureと通常のJavaScript実行経路は引き続き区別しています。

## 検証と配布

リリースタグで実行する[Release workflow](https://github.com/ieee0824/omoikane/actions/workflows/release.yml)が、JIT release gateと配布アーカイブの検査に成功した後、GitHub Releaseへ成果物を添付します。
