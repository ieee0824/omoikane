# Omoikane

フルスクラッチで実装するヘッドレスブラウザ。

## 概要

Omoikaneは、Rustで一から構築するヘッドレスブラウザエンジンです。Chrome DevTools Protocol（CDP）互換のAPIを提供し、任意の言語から利用できることを目指しています。

## 特徴

- **Rust製** — メモリ安全性とパフォーマンスを両立
- **フルスクラッチ** — HTTP、HTML/CSSパーサー、レイアウトエンジンをすべて自前実装
- **CDP互換** — Puppeteer/Playwright等の既存エコシステムから利用可能
- **C FFI** — 薄いCバインディングにより、あらゆる言語から呼び出し可能
